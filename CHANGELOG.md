# История изменений

## v0.1.5

- Compose даёт API 30 секунд на остановку вместо 15, чтобы после завершения HTTP-запросов осталось время на закрытие соединений PostgreSQL.
- Go CI проверяет, что итоговая конфигурация Compose даёт API 30 секунд на остановку.
- Нагрузочный тест засчитывает только ответы `302` с единственным заголовком `Location`, который совпадает с адресом тестовой ссылки.
- HTTP-обработчики создания и чтения ссылок разнесены по отдельным файлам.

HTTP API и схема базы сохранены. [OpenAPI](docs/openapi.yaml).

## v0.1.4

- Закрытие пула PostgreSQL больше не прерывает отправку `CancelRequest` для уже выполняющегося SQL. Быстрая остановка зависших подключений сохранена.
- Добавлена регрессия с блокировкой строки: проверяются завершение серверного запроса и отсутствие изменения счётчика после отмены и закрытия хранилища.
- В инструкции развёртывания уточнён отдельный таймаут очистки готовых соединений pgx.

HTTP API и схема базы сохранены. [OpenAPI](docs/openapi.yaml).

## v0.1.3

- Исправлено зависание остановки при восстановлении минимального пула PostgreSQL: незавершённые подключения прерываются перед закрытием пула, после завершения HTTP-запросов.
- Подключение к PostgreSQL по умолчанию ограничено 5 секундами; явный положительный `connect_timeout` сохраняется.
- Добавлены проверки полной остановки приложения при зависшем handshake, отмены запуска и конкурентного закрытия подключений.
- В README уточнены требования для тестов, лимит создания ссылок и описание Docker-проверки.

HTTP API и схема базы сохранены. [OpenAPI](docs/openapi.yaml).

## v0.1.2

- Код API разделён на пакеты приложения, логики ссылок, HTTP и хранилищ.
- Некорректные коды ссылок возвращают `404` до обращения к базе.
- Миграции принимают параметры пула PostgreSQL; некорректный период проверки пула отклоняется без panic.
- Проверки целостности и безопасности релиза работают и при `python -O`.
- Ссылки OpenAPI в заметках внутри ZIP/tar-архивов ведут на включённую спецификацию.
- Для golang-migrate подключён форк с закрытием и ожиданием буферов при ошибках миграции.
- Пользовательская документация очищена от внутренних сценариев и устаревших инструкций выпуска.

HTTP API и схема базы сохранены. [OpenAPI](docs/openapi.yaml).

## v0.1.1

- Исправлены ссылки и оформление описания GitHub Release.
- Удалена неиспользуемая директива Go tool; для Go-файлов закреплены окончания строк LF.

## v0.1.0

Первый выпуск: короткие ссылки и статистика, PostgreSQL и миграции, кеш Redis, лимитер, API-ключ, структурированные логи и graceful shutdown. Доступны Docker-образ и архивы для Linux/macOS amd64/arm64 и Windows amd64.
