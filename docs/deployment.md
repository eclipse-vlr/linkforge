# Развёртывание LinkForge

> Публичный стенд пока не развёрнут. Docker-образ собран и проверен локально: PostgreSQL, работа с Redis и без него, отказ Redis, авторизация, редиректы, статистика и корректная остановка. Сборка и проверка контейнера также включены в CI.

## Требования

- Docker-хостинг, умеющий собирать корневой [`Dockerfile`](../Dockerfile), например Railway.
- PostgreSQL с постоянным хранилищем и отдельным паролем. Redis — необязателен.
- Переменные окружения должны храниться в секретах хостинга, а не в GitHub.
- **Один экземпляр приложения:** миграции выполняются при старте, а лимитер по IP хранится в памяти процесса.

## Сценарий для Railway

1. Подключи репозиторий `eclipse-vlr/linkforge` к сервису Railway, выбери сборку из `Dockerfile`.
2. Создай PostgreSQL в том же Railway-проекте. Передай сервису API `DATABASE_URL` из приватного подключения к базе через переменные Railway. Не используй тестовый пароль из `docker-compose.yml`.
3. Redis можно не подключать: если `REDIS_URL` пустой, приложение работает напрямую с PostgreSQL. Если подключать Redis, передай корректный `redis://` или `rediss://` URL из переменных.
4. Railway задаёт `PORT`; команда запуска в Dockerfile настраивает `HTTP_ADDR` на `0.0.0.0:$PORT`. При необходимости можно явно определить `HTTP_ADDR`.
5. **Обязательно для публичного доступа:** задай длинный случайный `CREATE_LINK_API_KEY` в защищённых переменных Railway. Тогда `POST /api/v1/links` требует заголовок `X-API-Key`, а просмотр статистики и переходы остаются публичными. Не помещай ключ в исходники или профиль.
6. Сгенерируй публичный домен для сервиса. Укажи `BASE_URL=https://<твой-домен>` без пути, query или завершающего слеша. После изменения `BASE_URL` перезапусти приложение.
7. Проверь логи миграций и подключения к PostgreSQL. Затем проверь `GET /healthz`, создание ссылки, ответ `302` и статистику переходов. `/healthz` сам по себе **не** проверяет БД.
8. Только после проверки реального URL добавь его в профиль GitHub.

## Переменные для Railway

Для сервиса API в Railway следует настроить:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` — ссылка на переменную **созданного** сервиса PostgreSQL |
| `BASE_URL` | `https://<домен>.up.railway.app` — только после получения реального домена |
| `CREATE_LINK_API_KEY` | Длинный случайный секрет, заданный через Variables/Secrets Railway |
| `REDIS_URL` | Не задавать при первом деплое: Redis необязателен |

Не копируй значения паролей или ключа в GitHub. Имя сервиса базы данных в ссылке должно совпадать с именем в твоём Railway-проекте (в примере — `Postgres`). Настрой проверку здоровья API по пути `/healthz`, но помни, что она не заменяет проверку соединения с базой. Для первого запуска оставь одну реплику.

## Почему публичная демонстрация требует осторожности

Без `CREATE_LINK_API_KEY` любой пользователь может создавать перенаправления на произвольные HTTP/HTTPS URL. Это риск спама и фишинга. Для публичного стенда обязательно настрой ключ, храни его в секретах Railway, не публикуй в GitHub. Лимитер в памяти всё равно **не** заменяет мониторинг, квоты и защиту от злоупотреблений.

Для открытого интернета прежде чем делиться ссылкой рекомендуется настроить мониторинг, защищённый доступ к созданию ссылок и резервные копии PostgreSQL. Пока безопаснее закрытый тестовый стенд.

## Локальная проверка Docker-образа

```powershell
docker build -t linkforge:local .
docker compose up -d --wait db
docker run --rm -p 127.0.0.1:8080:8080 `
  -e DATABASE_URL='postgres://linkforge:devpassword@host.docker.internal:5432/linkforge?sslmode=disable' `
  -e BASE_URL='http://localhost:8080' linkforge:local
```

Этот пример рассчитан на Docker Desktop под Windows. Для Docker Engine под Linux используй общую сеть Compose, чтобы API подключался к PostgreSQL по имени `db`:

```bash
docker build -t linkforge:local .
docker compose -p linkforge up -d --wait db
docker run --rm --network linkforge_default -p 127.0.0.1:8080:8080 \
  -e DATABASE_URL='postgres://linkforge:devpassword@db:5432/linkforge?sslmode=disable' \
  -e BASE_URL='http://localhost:8080' linkforge:local
```
