# Запуск готовой сборки

Для этого способа Go не нужен. Выбери архив под свою систему, распакуй его целиком и открой терминал в получившейся папке. Рядом с программой должна остаться папка `migrations`.

Понадобится PostgreSQL 17 с созданной базой. При первом запуске LinkForge сам создаст таблицы, поэтому пользователю базы нужны права на изменение схемы. Redis можно подключить позже.

В примерах ниже замени `user`, `password` и имя базы своими значениями.

## Linux и macOS

```bash
export DATABASE_URL='postgres://user:password@127.0.0.1:5432/linkforge?sslmode=disable'
export BASE_URL='http://localhost:8080'
./linkforge
```

## Windows PowerShell

```powershell
$env:DATABASE_URL = 'postgres://user:password@127.0.0.1:5432/linkforge?sslmode=disable'
$env:BASE_URL = 'http://localhost:8080'
.\linkforge.exe
```

После запуска API доступен на `http://localhost:8080`. Открой `/healthz`, чтобы проверить, что сервер отвечает. Описание запросов лежит в `openapi.yaml` внутри архива. Остановить сервер можно через Ctrl+C.

## Если нужны другие настройки

- Другой порт: задай `HTTP_ADDR`, например `:9090`, и поменяй `BASE_URL` на `http://localhost:9090`.
- Кеш: задай `REDIS_URL`, например `redis://127.0.0.1:6379/0`. При сбое Redis приложение продолжит обращаться к PostgreSQL.
- Защита создания ссылок: задай `CREATE_LINK_API_KEY` и передавай её значение в заголовке `X-API-Key` POST-запроса.

Настройки читаются из окружения; `.env` автоматически не загружается. Для удалённой базы включи TLS по требованиям хостинга. Коммит, из которого собран архив, указан в `RELEASE_COMMIT`.
