# LinkForge v0.1.1

> Кандидат в технический выпуск после v0.1.0.

Обновление инструментов и оформления релиза. [Описание API](openapi.yaml).

## Что изменилось

- Ссылки на OpenAPI в описании GitHub Release указывают на коммит сборки.
- Из публикуемого описания исключены служебный статус и инструкция публикации.
- Удалена неиспользуемая директива Go tool для библиотеки миграций.
- Для Go-файлов закреплены окончания строк LF.

## Проверка выпуска

Для коммита выпуска должны пройти **Go CI** и **HTTP benchmark**: тесты с PostgreSQL и Redis, проверка гонок и уязвимостей, сборка и проверка Docker-образа.

При подготовке архивов отдельно проверяется распакованная Linux-сборка: API-ключ, 500 редиректов, сохранение статистики и корректная остановка. Для скачивания готовятся Linux и macOS amd64/arm64, Windows amd64 и исходники. Контрольные суммы находятся в `SHA256SUMS`.

## Ограничения

Лимитер работает в памяти одного экземпляра. Статистика публичная, учитывает повторные обращения и ботов; при ошибке записи счётчика часть переходов может не попасть в статистику. Compose предназначен для локальной разработки.

## Подготовка и публикация

1. Дождись зелёных **Go CI** и **HTTP benchmark** нужного коммита в `master`.
2. Запусти **Actions → Prepare draft release → Run workflow** для `master` и `v0.1.1`.
3. Проверь описание и 10 файлов черновика, затем нажми **Publish release**.

Workflow проверяет размеры и SHA-256 загруженных файлов. Тег должен соответствовать коммиту сборки; опубликованные выпуски workflow не изменяет.
